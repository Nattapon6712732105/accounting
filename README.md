# Enterprise Accounting — คู่มือการใช้งาน

ระบบบันทึกและจัดการบัญชีองค์กร (Enterprise Accounting) เป็นแอปพลิเคชัน Flutter สำหรับบันทึกรายรับ-รายจ่าย ตรวจสอบธุรกรรมทางการเงิน และสรุปยอดอย่างแม่นยำ โดยข้อมูลถูกเก็บไว้บนเซิร์ฟเวอร์ผ่าน REST API และปลอดภัยด้วยระบบ JWT Token

## คุณสมบัติหลักของระบบ

| คุณสมบัติ | รายละเอียด |
|---|---|
| 🔐 การยืนยันตัวตนด้วย JWT Token | เข้าถึงข้อมูลอย่างปลอดภัยผ่านระบบสิทธิ์ผู้ใช้งาน |
| 💰 บันทึก/จัดการรายรับ-รายจ่าย | เพิ่มรายการบัญชี พร้อมอัปเดตข้อมูลแบบ Real-time |
| 📊 สรุปยอดประจำเดือน | ดูรายรับ รายจ่าย และยอดคงเหลือของเดือนปัจจุบัน |
| 🏷️ หมวดหมู่มาตรฐาน | หมวดหมู่รายรับและรายจ่ายแยกกันชัดเจน พร้อมกราฟสรุปตามหมวดหมู่ |
| 👤 จัดการโปรไฟล์ | แก้ไขข้อมูลส่วนตัวและตั้งชื่อสำหรับทักทาย |
| 🔄 ข้อมูลอัปเดตอัตโนมัติ | ทุกหน้าจอรีเฟรชข้อมูลเองเมื่อมีการเพิ่มรายการใหม่ |

## การติดตั้งและรันแอป

**ข้อกำหนด:**
- ติดตั้ง [Flutter SDK](https://docs.flutter.dev/get-started/install) เวอร์ชันที่รองรับ Dart SDK `^3.12.1`
- อุปกรณ์/เครื่องมือสำหรับรัน (Android Emulator, iOS Simulator, Web, Windows, macOS, Linux)

**ขั้นตอนการรัน:**

```bash
# 1. ติดตั้ง dependencies
flutter pub get

# 2. รันแอปพลิเคชัน (เลือก platform ตามต้องการ)
flutter run
```

**การระบุ URL ของ Backend (ไม่บังคับ):**

แอปจะเชื่อมต่อกับเซิร์ฟเวอร์ Production โดยอัตโนมัติ (https://flutter-backend-iota.vercel.app/api) หากต้องการใช้เซิร์ฟเวอร์อื่น ให้ระบุผ่าน `--dart-define`:

```bash
# ตัวอย่าง: ใช้กับ Android Emulator (เซิร์ฟเวอร์ที่เครื่องตัวเอง)
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:3000/api

# ตัวอย่าง: ใช้กับ Web/iOS Simulator
flutter run --dart-define=API_BASE_URL=http://localhost:3000/api
```

## การเริ่มต้นใช้งาน

### ลงทะเบียนบัญชีใหม่

1. เปิดแอป แล้วกดปุ่ม **«ลงทะเบียน»** หรือ **«ลงทะเบียนใช้งาน»**
2. กรอกข้อมูลให้ครบทุกช่อง:
   - **ชื่อจริง (First Name)** — เช่น `สมชาย`
   - **นามสกุล (Last Name)** — เช่น `ใจดี`
   - **อีเมล (Email)** — เช่น `somchai@company.com`
   - **รหัสผ่าน (Password)** — กดรูปตา 👁️ เพื่อแสดง/ซ่อนรหัสผ่าน
3. กดปุ่ม **«ยืนยันลงทะเบียน»**
4. เมื่อลงทะเบียนสำเร็จ ระบบจะพาเข้าสู่หน้า **ภาพรวม** โดยอัตโนมัติ พร้อมข้อความต้อนรับ

> ⚠️ หากกรอกข้อมูลไม่ครบ ระบบจะแจ้งเตือน «กรุณากรอกข้อมูลให้ครบทุกช่อง»

### เข้าสู่ระบบ

1. เปิดแอป แล้วกดปุ่ม **«เข้าสู่ระบบ»**
2. กรอก **อีเมล** และ **รหัสผ่าน** ที่ลงทะเบียนไว้
3. กดปุ่ม **«Login»**
4. เมื่อล็อกอินสำเร็จ ระบบจะพาเข้าสู่หน้า **ภาพรวม**

> 💡 ระบบจะจำสถานะล็อกอินไว้บนเครื่อง (Token ถูกเก็บอย่างปลอดภัย) ครั้งต่อไปที่เปิดแอปจะไม่ต้องล็อกอินใหม่

### ออกจากระบบ

มี 2 วิธี:

- **ผ่านเมนู Drawer:** กดปุ่ม ☰ (มุมซ้ายบน) → เลือก **«ออกจากระบบ»**
- **ผ่านหน้าโปรไฟล์:** ไปที่แท็บ **โปรไฟล์** (ไอคอนคน) → เลื่อนลงล่างสุด → กดปุ่ม **«ออกจากระบบ (Logout)»**

## คู่มือการใช้งานแต่ละหน้าจอ

### หน้าหลัก (หน้าแรก)

เป็นหน้าแนะนำระบบ แสดงชื่อระบบและปุ่มเข้าถึงหลัก 2 ปุ่ม:

- **«เข้าสู่ระบบ»** — ไปที่หน้าล็อกอิน
- **«ลงทะเบียน»** — ไปที่หน้าสมัครสมาชิก

### หน้าภาพรวม (Dashboard)

แท็บแรกของแอปหลังจากล็อกอิน แสดงข้อมูลการเงินของ **เดือนปัจจุบัน** ประกอบด้วย:

1. **สรุปยอดเดือนนี้**
   - **รายรับ** 🟢 — ยอดเงินเข้ารวมของเดือนนี้
   - **รายจ่าย** 🔴 — ยอดเงินออกของเดือนนี้
   - **คงเหลือ** — รายรับลบรายจ่าย

2. **การเข้าถึงด่วน** — ปุ่มลัด 4 ปุ่ม:
   - **เพิ่มรายการ** ➕ — ไปที่หน้าบันทึกรายการใหม่
   - **รายการบัญชี** — ไปที่แท็บรายการ
   - **หมวดหมู่** — ไปที่แท็บหมวดหมู่
   - **รีเฟรช** 🔄 — โหลดข้อมูลใหม่

3. **รายการล่าสุด** — แสดง 4 รายการล่าสุด โดยรายรับแสดงด้วยเครื่องหมาย `+` สีเขียว รายจ่ายแสดงด้วย `-` สีแดง

> 💡 ดึงหน้าจอลง (Pull to Refresh) เพื่อโหลดข้อมูลใหม่

### หน้ารายการบัญชี

แท็บที่ 2 (ไอคอนใบเสร็จ 🧾) แสดงรายการบัญชีทั้งหมดของคุณ โดยเรียงรายการใหม่ล่าสุดก่อน:

- จำนวนรายการทั้งหมดแสดงอยู่มุมขวาบน เช่น `12 รายการ`
- แต่ละรายการแสดง: ประเภท (ลูกศรขึ้น/ลง), ชื่อรายการ, วันที่และหมวดหมู่, และจำนวนเงิน
- หากยังไม่มีรายการ ระบบจะแสดงข้อความแนะนำให้เพิ่มรายการแรก
- ดึงหน้าจอลง (Pull to Refresh) เพื่อโหลดข้อมูลล่าสุด

> 💡 รายการที่ยังไม่มีคำอธิบาย จะแสดงชื่อหมวดหมู่แทนชื่อรายการ

### หน้าพิมพ์/เพิ่มรายการบัญชี

กดปุ่ม **«เพิ่มรายการ»** จากหน้าภาพรวม หรือเลือก **«เพิ่มรายการใหม่»** จากเมนู ☰ เพื่อบันทึกรายการบัญชีใหม่ ตามขั้นตอน:

1. **เลือกประเภท** — กดปุ่มเลือกระหว่าง **«รายจ่าย»** หรือ **«รายรับ»**
2. **จำนวนเงิน (บาท)** — ต้องมากกว่า 0 (รองรับทศนิยม)
3. **หมวดหมู่** — เลือกจากรายการ dropdown (หมวดหมู่จะเปลี่ยนตามประเภทที่เลือก)
4. **รายละเอียด (ไม่บังคับ)** — บันทึกคำอธิบายหรือหมายเหตุของรายการ
5. **วันที่** — ค่าเริ่มต้นเป็นวันปัจจุบัน กดเพื่อเปิดปฏิทินเลือกวันอื่น
6. กดปุ่ม **«บันทึก»**

เมื่อบันทึกสำเร็จ จะมีข้อความ «บันทึกรายการสำเร็จ» และทุกหน้าจอจะอัปเดตยอดให้อัตโนมัติ

> ⚠️ ระบบจะตรวจสอบจำนวนเงินและหมวดหมู่ หากไม่ถูกต้องจะแจ้งเตือนและไม่บันทึก

### หน้าหมวดหมู่

แท็บที่ 3 (ไอคอนหมวดหมู่ 🗂️) แสดง:

1. **กราฟสรุปตามหมวดหมู่** — สรุปยอดรวมทั้งหมดของรายรับ-รายจ่ายในกราฟเดียว
   - รายรับแสดงสีเขียว / รายจ่ายแสดงสีแดง
   - แต่ละหมวดหมู่แสดงยอดรวมและจำนวนครั้ง
2. **หมวดหมู่รายรับ** — รายการหมวดหมู่ยอดเงินเข้า
3. **หมวดหมู่รายจ่าย** — รายการหมวดหมู่ยอดเงินออก

### หน้าโปรไฟล์

แท็บที่ 4 (ไอคอนคน 👤) แสดงข้อมูลส่วนตัวของคุณ:

- **ข้อความทักทาย** — แสดงตามช่วงเวลาของวัน (เช้า/บ่าย/เย็น) พร้อมชื่อของคุณ
- **ตั้งชื่อสำหรับทักทาย** — กดปุ่มเพื่อตั้งชื่อที่ต้องการให้ระบบเรียก (เก็บไว้เฉพาะเครื่องของคุณ)
- **ประวัติส่วนตัว** — ประกอบด้วย:
  - User ID
  - อีเมลองค์กร
  - ชื่อ-นามสกุล
  - ระบบปฏิบัติการที่ใช้งานอยู่ (Active OS)
  - วันที่สมัครสมาชิก
- ปุ่ม **«ออกจากระบบ (Logout)»** — อยู่ล่างสุด

### หน้าตั้งค่า

เข้าได้จากเมนู ☰ → **«ตั้งค่า»** สำหรับแก้ไขข้อมูลส่วนตัว:

- **ชื่อสำหรับทักทาย (Display Name)** — ชื่อที่แสดงในหน้าโปรไฟล์
- **ชื่อจริง (First Name)**
- **นามสกุล (Last Name)**
- **อีเมล (Email)**

กด **«บันทึกข้อมูล»** เมื่อแก้ไขเสร็จ ระบบจะแจ้ง «บันทึกข้อมูลส่วนตัวเรียบร้อย»

> ⚠️ ต้องกรอกชื่อ นามสกุล และอีเมลให้ครบก่อนบันทึก

## การแก้ปัญหาเบื้องต้น

| ปัญหา | สาเหตุ/วิธีแก้ไข |
|---|---|
| «ไม่ได้รับอนุญาต: Token หมดอายุ» | เซสชันหมดอายุ ให้ล็อกอินใหม่ |
| «เกิดข้อผิดพลาดจากเซิร์ฟเวอร์ (500)» | ปัญหาฝั่งเซิร์ฟเวอร์ โปรดลองอีกครั้งภายหลัง |
| «ส่งคำขอถี่เกินไป (429)» | ทำรายการถี่เกินไป รอสักครู่แล้วลองใหม่ |
| «ไม่พบข้อมูลที่ต้องการ (404)» | ข้อมูลอาจถูกลบไปแล้ว หรือ URL ไม่ถูกต้อง |
| «โหลดหมวดหมู่ไม่สำเร็จ» | ตรวจการเชื่อมต่ออินเทอร์เน็ต แล้วลองเปิดหน้าอีกครั้ง |
| หน้าจอค้าง/ข้อมูลไม่โหลด | ดึงหน้าจอลงเพื่อรีเฟรช หรือกดปุ่ม «ลองอีกครั้ง» / «รีเฟรช» |
| อยากเปลี่ยนเซิร์ฟเวอร์ | รันด้วย `--dart-define=API_BASE_URL=...` ตามหัวข้อการติดตั้ง |

## ข้อมูลทางเทคนิค

**โครงสร้างเมนูหลัก (Bottom Navigation):**

| ลำดับ | ชื่อแท็บ | ฟังก์ชัน |
|---|---|---|
| 1 | ภาพรวม | สรุปยอดเดือน, ทางลัด, รายการล่าสุด |
| 2 | รายการ | รายการบัญชีทั้งหมด |
| 3 | หมวดหมู่ | กราฟสรุปและหมวดหมู่ |
| 4 | โปรไฟล์ | ข้อมูลส่วนตัว, ออกจากระบบ |

**API Endpoint ที่ใช้ (Base URL: `.../api`):**

| เมธอด | Endpoint | ฟังก์ชัน |
|---|---|---|
| POST | `/auth/register` | ลงทะเบียน |
| POST | `/auth/login` | เข้าสู่ระบบ |
| GET | `/auth/me` | ดึงข้อมูลผู้ใช้ |
| PATCH | `/auth/me` | แก้ไขข้อมูลผู้ใช้ |
| POST | `/auth/logout` | ออกจากระบบ (ยกเลิก Token) |
| GET | `/categories` | ดึงหมวดหมู่ |
| GET | `/reports/summary` | สรุปยอดและสัดส่วนตามหมวดหมู่ |
| GET | `/transactions` | ดึงรายการบัญชี (รองรับการกรอง/แบ่งหน้า) |
| POST | `/transactions` | สร้างรายการ |
| PUT | `/transactions/:id` | แก้ไขรายการ |
| DELETE | `/transactions/:id` | ลบรายการ |

**โครงสร้างโฟลเดอร์หลัก:**

```
lib/
├── core/          # Theme และไอคอนหมวดหมู่
├── models/        # ตัวแบบข้อมูล (User, Transaction, Summary...)
├── screens/       # หน้าจอทั้งหมด (Dashboard, Transactions, Login...)
├── services/      # API Service และ Token Storage
├── widgets/       # Widget ที่ใช้ร่วมกัน
└── main.dart      # จุดเริ่มต้นของแอป
```
