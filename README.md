# accounting (Enterprise Accounting)

แอปพลิเคชัน Flutter สำหรับบันทึกและจัดการบัญชีรายรับ-รายจ่ายขององค์กร เชื่อมต่อกับ REST API Backend ผ่าน JWT Token

## คุณสมบัติหลัก

- ยืนยันตัวตนด้วย JWT Token (เข้าสู่ระบบ / ลงทะเบียน / ออกจากระบบ)
- เพิ่ม แก้ไข ลบ รายการรายรับ-รายจ่าย
- สรุปยอด รายรับ รายจ่าย คงเหลือ รายเดือน
- กราฟสรุปยอดตามหมวดหมู่
- จัดการข้อมูลส่วนตัว (ชื่อ นามสกุล อีเมล ชื่อสำหรับทักทาย)

## การติดตั้งและรันโปรเจกต์

```bash
flutter pub get
flutter run
```

กำหนด URL ของ API ได้ผ่าน `--dart-define` (ค่าเริ่มต้นคือ Production Server):

```bash
# ใช้ Production (ค่าเริ่มต้น)
flutter run

# ใช้ API ตัวอื่น เช่น Android Emulator
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:3000/api

# iOS Simulator / Web
flutter run --dart-define=API_BASE_URL=http://localhost:3000/api
```

## วิธีการใช้งาน

### 1. เริ่มต้นใช้งาน

- เปิดแอปพลิเคชัน จะเจอหน้าแรกซึ่งมีปุ่ม **เข้าสู่ระบบ** และ **ลงทะเบียน**
- ยังไม่มีบัญชี → กด **ลงทะเบียน** กรอก ชื่อจริง นามสกุล อีเมล และรหัสผ่าน แล้วกด **ยืนยันลงทะเบียน** (ระบบจะเข้าสู่ระบบให้อัตโนมัติ)
- มีบัญชีแล้ว → กด **เข้าสู่ระบบ** กรอกอีเมลและรหัสผ่าน แล้วกด **Login**

หลังจากล็อกอินแล้วจะเข้าสู่หน้าหลักซึ่งมีแถบเมนูด้านล่าง 4 แท็บ

### 2. แท็บภาพรวม (Dashboard)

แสดงข้อมูลสรุปของเดือนปัจจุบัน ได้แก่:

- **สรุปยอดเดือนนี้** — ยอดคงเหลือ รายรับ และรายจ่ายทั้งเดือน
- **การเข้าถึงด่วน** — ปุ่มลัดสำหรับ เพิ่มรายการ / รายการบัญชี / หมวดหมู่ / รีเฟรช
- **รายการล่าสุด** — รายการรายรับ-รายจ่ายล่าสุด 4 รายการ

### 3. แท็บรายการบัญชี (Transactions)

- แสดงรายการทั้งหมด พร้อมปุ่มกรอง **ทั้งหมด / รายรับ / รายจ่าย**
- กดปุ่มลอย **เพิ่มรายการ** เพื่อเพิ่มรายการใหม่
- แตะที่รายการเพื่อ **แก้ไข** (เปลี่ยนรายรับ-รายจ่าย จำนวนเงิน หมวดหมู่ รายละเอียด วันที่)
- ลบรายการได้ 2 วิธี:
  - ปัดรายการไปทางซ้าย (Swipe)
  - เข้าแก้ไขแล้วกดปุ่ม **ลบรายการนี้** (ระบบจะให้ยืนยันอีกครั้งก่อนลบ)

### 4. เพิ่ม/แก้ไขรายการ

แบบฟอร์มประกอบด้วย:

- **ประเภท** — เลือกว่ารายรับหรือรายจ่าย (สลับได้ตลอดเวลา)
- **จำนวนเงิน** — บังคับกรอก ต้องมากกว่า 0
- **หมวดหมู่** — บังคับเลือก จากหมวดหมู่ที่กำหนดตามประเภทที่เลือก
- **รายละเอียด** — ไม่บังคับ ใช้เป็นชื่อแสดงของรายการ
- **วันที่** — แตะเพื่อเลือกวันที่ (ค่าเริ่มต้นเป็นวันนี้)

กด **บันทึกรายการ** เมื่อกรอกครบ ระบบจะอัปเดตหน้าจออื่นแบบ Real-time

### 5. แท็บหมวดหมู่ (Categories)

- **กราฟสรุปตามหมวดหมู่** — แสดงยอดรวมรายรับ-รายจ่ายของทุกหมวดหมู่ (รายรับสีเขียว รายจ่ายสีแดง)
- **หมวดหมู่รายรับ / รายจ่าย** — แสดงไอคอนหมวดหมู่พร้อมยอดรวมต่อหมวด
- แตะที่หมวดหมู่ใดเพื่อดูรายการทั้งหมดในหมวดนั้น พร้อมยอดรวม และสามารถแก้ไข/ลบได้

### 6. แท็บโปรไฟล์ (Profile)

- ตั้ง **ชื่อสำหรับทักทาย** (Display Name) ที่แสดงในหน้าโปรไฟล์
- ดูข้อมูลส่วนตัว: User ID, อีเมล, ชื่อ-นามสกุล, ระบบปฏิบัติการ และวันที่สมัคร
- กด **ออกจากระบบ** เพื่อล็อกเอาต์ (Token จะถูกล้างออกจากเครื่อง)

### 7. เมนูตั้งค่า (Settings)

เข้าได้จากแฮมเบอร์เมนู (Drawer) ด้านซ้ายบน → **ตั้งค่า**

- แก้ไขข้อมูลส่วนตัว: ชื่อสำหรับทักทาย, ชื่อจริง, นามสกุล, อีเมล
- กด **บันทึกข้อมูล** เพื่อบันทึกการเปลี่ยนแปลง

### 8. เมนูอื่น ๆ ใน Drawer

- **เพิ่มรายการใหม่** — ไปยังหน้าบันทึกรายการทันที
- **ออกจากระบบ** — ล็อกเอาต์และกลับไปหน้า Login

## โครงสร้างโปรเจกต์ (lib/)

| โฟลเดอร์ | คำอธิบาย |
| --- | --- |
| `screens/` | หน้าจอต่าง ๆ เช่น Login, Register, Dashboard, Transactions, Categories, Profile, Settings |
| `models/` | โมเดลข้อมูล (Transaction, Category, Summary ฯลฯ) |
| `services/` | เรียก API (`api_service.dart`), จัดเก็บ Token (`token_storage.dart`), จัดการสถานะ (`app_state.dart`) |
| `widgets/` | คอมโพเนนต์ UI ที่ใช้ซ้ำ เช่น การ์ด, ไทล์รายการ, เมนู Drawer |
| `core/` | ธีม, ฟอร์แมตตัวเลข/วันที่, ไอคอนหมวดหมู่ |
